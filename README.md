## Comparing Builds

Every build of the Editor's Copy is a commit on the `gh-pages` branch, so any two builds can be compared. The repository is private, so these links need a GitHub login.

* [Build history of the text version](https://github.com/jaimejim/ietf-draft-ard-initial-contact/commits/gh-pages/draft-jimenez-dawn-ard-initial-contact.txt): one entry per build; open an entry to see what that build changed.
* Any two builds: `https://github.com/jaimejim/ietf-draft-ard-initial-contact/compare/<older>...<newer>`, with `gh-pages` as `<newer>` for the latest. Example: [latest build versus the build of 2026-10-22](https://github.com/jaimejim/ietf-draft-ard-initial-contact/compare/c3c48ba...gh-pages). The draft was renamed on 2026-10-28; comparisons that cross that date show the old name under a branch folder and the new name as added, while comparisons from build `04b3869` onward are clean.
* The same two builds locally, across the rename:

```sh
$ git fetch origin gh-pages
$ git diff --word-diff c3c48ba:draft-jimenez-ard-initial-contact.txt \
    origin/gh-pages:draft-jimenez-dawn-ard-initial-contact.txt
```
